MCP OAuth en VS Code: análisis técnico

El flujo de autenticación automática de VS Code y el abuso de OAuth en servidores MCP.

Por Marcelo Burgos · Investigación de Hackfluency Research

VS Code implementa la especificación completa de MCP: tools, prompts, resources y autenticación OAuth 2.1. Cuando un servidor MCP requiere autorización, el cliente ejecuta automáticamente el descubrimiento OAuth, se registra dinámicamente y abre el navegador. El usuario solo ve un clic en Allow.

Ese comportamiento no es un bug: es la especificación funcionando como fue diseñada. Y por eso es explotable.

Qué cubre el informe completo

  • El flujo del ataque paso a paso: descubrimiento, registro dinámico y página de consentimiento.
  • Por qué el usuario no puede distinguir el servidor legítimo del controlado por el atacante.
  • Qué datos quedan expuestos y cuáles no, con evidencia del PoC.
  • Mitigaciones para equipos: allowlists, revisión de metadata, scopes mínimos y logging.
  • Contexto de junio de 2026 y comparación con casos similares.
