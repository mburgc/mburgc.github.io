MCP OAuth in VS Code: Technical Analysis

VS Code's automatic authentication flow and OAuth abuse in MCP servers.

By Marcelo Burgos · Hackfluency Research

VS Code implements the full MCP specification: tools, prompts, resources and OAuth 2.1 authentication. When an MCP server requires authorization, the client automatically runs OAuth discovery, registers dynamically and opens the browser. The user only sees an Allow click.

That behavior is not a bug: it is the specification working as designed. Which is exactly why it is exploitable.

What the full report covers

  • The attack flow step by step: discovery, dynamic registration and the consent page.
  • Why the user cannot tell the legitimate server from the attacker-controlled one.
  • What data is exposed and what is not, with PoC evidence.
  • Mitigations for teams: allowlists, metadata review, least-privilege scopes and logging.
  • June 2026 context and comparison with similar cases.
